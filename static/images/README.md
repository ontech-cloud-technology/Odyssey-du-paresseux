# Images du Site

## Logo
- `logo.png` : Logo principal de "L'Odyssée du Paresseux"

## Images de Paresseux
Pour ajouter des images de paresseux à la galerie, placez vos images dans ce dossier avec les noms suivants :
- `sloth1.jpg` - Paresseux à Deux Doigts
- `sloth2.jpg` - Paresseux à Trois Doigts
- `sloth3.jpg` - Jeunes paresseux
- `sloth4.jpg` - Enthousiasme pour Sloth Air
- `sloth5.jpg` - Paresseux dans la Canopée
- `sloth6.jpg` - Habitat Naturel

## Formats supportés
- JPG / JPEG
- PNG
- WebP

## Taille recommandée
- Largeur : 800-1200px
- Hauteur : 600-900px
- Ratio : 4:3 ou 16:9

Les images seront automatiquement redimensionnées et affichées dans la galerie.
